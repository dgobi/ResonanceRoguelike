shape a furnished variant, add direct useful items/readables/containers, declare
entrances and goals, recover exact drafts after host restart, publish/reopen/revise
one file and inspect its actual production construction in every permitted
orientation. No canonical example pack or world membership was installed.

## Compatibility, gates and limits

Same-ID consumed building/pool/item changes can reject an already selected pending
planned surface through its saved semantic closure; restoring matching definitions
restores eligibility. Adding a variant leaves old selected dependencies intact.
Inactive structure metadata keeps its existing semantic behavior. The focused
fixture uses actual `dependencies`/`check_dependencies`; retained broad G3/G5 owned
scene/cache and missing-cache tests preserve generated-map, removed-loot and refusal
guarantees. A new building ID does not insulate shared pools/items from later edits.
Generated owned maps/contents/state remain authoritative without promising every
external definition lookup is frozen. W5O's pending-room demonstration does not
override the planned-surface gate. Both affected guides clarify this distinction.

Final [gates](evidence/w5p/gates.json) bind command logs and source identities:
85 frontend tests, TypeScript, 70 Rust tests, clippy with warnings denied, 108 worker
tests with one expected embedded-runtime skip plus its separate missing-dependency
control, 334 broad game tests with stable source, locked Windows executable/NSIS,
the complete native building journey, seven-owner shared-workspace lifecycle and
retained room capture/reset/latest/cold/fault lifecycle, and ordinary 128 × 128
main/default-slot save-load. The latter uses a font/data fixture with optional
sprite fallback warnings; no sprite-render fidelity is claimed. Worker/game checks use
pinned CPython 3.11.0 and exact dependencies; Node is 24.15.0 and Rust is 1.95.0.

[Excluded attempts](evidence/w5p/attempts.json) remain distinct from passing gates:
source-changing preliminary runs, adapted legacy source-free fixtures, corrected
mock variant identities, bounded BUSY/confirmation retries, camera-fit and actual
text-source harness assumptions, the corrected dropped origin location, and NSIS

completion evidence. Binaries and bulky full receipts/logs remain ignored.

These are revealed initial production previews, not player FOV, ordinary use,
safety, balance, natural discovery, lot-fit or road-connectivity certification.
The controlled planner supplies its separate bounded fit/materialization evidence.
Moving/resizing/rotating can change position-derived loot. Windows is verified;
installer UX/installation, other platforms and every historical special behavior
are not claimed. No selection editor, canonical pack, gameplay change, surface
play-session launcher, save migration, wiki or reference-pack rebuild is included.
