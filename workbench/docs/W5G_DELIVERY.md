## Repair checkpoint and authority

The bounded repair was committed before the room extension, with its focused
[repair evidence](W5G_REPAIR.md). Accepted unfinished intent and restore now share
admission: eligible variant-only text/recipe/template sources can restore exact
valid or invalid text with `variant:false` before choosing a target. No ID is
invented, no same-ID permission is granted and no review survives. Explicit
forbidden special-creature/typography variants remain refused. Baseline,
generation, fresh eligibility, claim-before-read and live-owner protection remain.
Exact duplicate diagnostics are removed at shared assembly after path translation;
all attributes, including severity, field and location, participate in equality.

Every family now declares explicit production-route metadata and a trusted
effective operation subset. The host freezes original operations and compares
fresh original-source policy at validation/apply. Original-candidate authorization
preserves protected values. Eligible ordinary immediate layout sources permit
edit/variant; the exact G17 template permits only a new layout publication.
Laboratory identity/source, unsupported shapes and ambiguous sources cannot be
promoted. The host independently confines writes to immediate layout files, maps
the documentation source to layouts for both variant recovery and publication,
and rejects documentation published facts. Descriptors/recovery cannot enlarge it.

Rooms now own shared tabs, mounted views, history, monitor, close/reload/reopen,
publication handoffs and durable recovery. Duplicate legacy room discovery and
worker dispatch were removed; buildings and pools retain their existing scope.
The spatial view uses `LayoutCanvas`/`MapView` and structured scene receipts,
independently of text/font PNG frames. The staged documentation candidate keeps
its true logical source/target and original hash while compiling in scratch data.

## Room controls and realized behavior

Terrain brush/rectangle/erase, one-character legend mappings including null,
deliberate top-left anchored rectangular resize, authored arrival and factual
fallback return settings share the exact Source draft. Unicode coordinates and
untouched JSON string escapes survive localized operations. Missing dimensions
are not inserted on open/resize; matching existing ones are updated. Unsafe resize
refuses stranded retained coordinates and inactive decor layers. One accepted
resize is one history operation. Null retains initial wall fill. Explicit painted
stairs suppress fallback exit fields; north/south uses exit_y and horizontal
midpoint, east/west uses exit_x and vertical midpoint.

Direct creatures, floor/readable items and containers support add/select/move/edit/
remove while preserving source order and metadata. Overlaps remain individually
selectable. Actual factory objects, carrier/readable binding, container decor and
ordered independent pools are distinguished. Reference choices show saved sources,
ambiguity and missing definitions; decor uses its real list registry. Linked
creature/text/item navigation returns to the same room/record; saved linked files
refresh choices. Unsaved parked dependencies never overlay room validation.

Underground population retains explicit item_id with `map_text=False` and assigns
the record text_id to that instance. Newly authored false readable bindings fail
with a correction. The small route-aware validator correction retains ordinary
building carrier mapping. Inactive decor_layer, legend_weights, top-level stairs_up,
type, rotatable and tags remain visible; they do not activate those behaviors.

The existing arrival selector now runs for every authored layout, with or without
creatures. The returned actual position is checked after population for bounds,
walkability, blocking decor/container/actor occupancy and a reachable usable
return. Unsafe centre fallback is rejected, without a second relocation algorithm
or cached-scene movement change. Closed-door authored start `[38,21]` correctly
reports actual `[37,20]` in both focused cases.

Derived static access uses production reach/interaction rules and the exact
receipt-owned objects. Relocated items retain source and realized coordinates;
an unrelated same-ID object cannot substitute. Receipts show actual carrier/text/
actor identities, selected pools, realized contents, authored/actual arrival,
return and legal container approaches. These are initial geometry/population/
static access observations, not FOV, combat balance, future safety or natural
selection. Resizing may change position-derived loot with a retained seed.
