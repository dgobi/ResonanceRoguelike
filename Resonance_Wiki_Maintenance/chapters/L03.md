# L03 — Put writing into the world

Make an ordinary found note, give it a physical carrier, and read it through inventory. The note tells the player what the nearby fire and watcher make possible; the fiction can be yours. Text identity, carrier identity and learned information are separate.

## Starting state and prediction

This lesson starts independently with the supplied workroom, `guide1_note` and `guide1_note_carrier`. You need only [the setup](#learning-path). The note is ordinary common prose; this lesson does not implement a new language or quest gate. Predict whether reading consumes the carrier, whether turning a page costs another turn, and what would happen if the carrier pointed to a missing text ID.

## Vary and diagnose

Copy the text to `authoring/guide1/note.json`, add a second page with a different practical clue, and run `practice.py L03 --draft authoring/guide1/note.json --output evidence/guide-1/l03-two-pages`. Keep ID `guide1_note` for the fixed fixture. In manual practice, Left/Right changes pages; Up/Down, Page Up/Page Down, Home/End scroll; Escape/Enter closes. Confirm the title, paragraphs and footer at the intended size.

**Fault:** change the carrier's `text_id` in a disposable candidate to `guide1_typo`. A valid item can then report missing text on use. Distinguish missing definition from an unreadable font by checking `engine.data.texts`/the diagnostic before changing typography. Restore the correct ID; the complete carrier above is the answer.

**Independent task:** write a clue with two plausible player responses, one dangerous and one cautious. Choose whether it needs one page or several. Keep the actual game requirements accurate: prose alone does not create a lock, reward or quest state. Acceptance is ordinary pickup/read, correct pages, stable carrier after use, and a clear link between clue and the authored place.

## Lifetime and restart

Running text catalogue requires restart to change; a loaded carrier retains its reference; new instances copy the chosen reference; unbuilt rooms use their saved definition/dependency rules; generated rooms retain carriers; new worlds still need placement. The text body lookup and stored page/span knowledge have different lifetimes. Rerun for a fresh fixture; no production files were written. Revisit later by tracing an unfamiliar readable object without searching its displayed title. Continue to [L06](#L06) or [L08](#L08).
