# L07 — Make a place appear naturally

Connect a room to underground selection and a cottage to surface settlement selection. These are distinct routes. A successful editor preview or debug spawn does not prove either one.

## Start and predict

The full room, cottage, note, ration and pool are supplied. L06 is optional. The controlled policy sets authored barrow chance to 1 and uses the practice cottage as residential membership to make the integration observable. This is route proof, not a recommendation for production prevalence.

```powershell

```

Predict which changes need a new world, which can affect an unbuilt old room, and why a pending planned surface might refuse changed definitions. The receipt records real `generate_world` assignments, real planned cottage placements, every admitted cottage orientation, actual underground entry and surface content construction. Initial player location at a selected entrance is explicitly staged; the run does not claim an expedition from the campaign start.

## Route B — Surface building and membership

Start with the complete `guide1_cottage.json` in the embedded examples. It includes geometry, front entrance/normal, required access targets, admitted rotations/mirroring, buffer and approach. Its contents reference the supplied text/item and `guide1_supplies` pool. Validate orientations first; a rotated door and its frontage must still agree.

The Selection editor can edit seven current membership lists. The distributed `policies/settlement_profiles.json` keeps the other policy intact and substitutes this residential entry in grid and roadside lists:

```json
{"asset":"guide1_cottage","weight":1,"max_per_settlement":20}
```

This is a **partial entry**, not a replacement for the whole file. The complete policy is bundled and embedded in the examples catalogue. `world_plan.py` records a selected placement with its asset, origin, transform, frontage and dependencies. `create_surface` realizes that plan. Building ID alone does not change explicit membership; legacy folder pools can nevertheless discover new production files, which is why practice definitions stay outside production scans.

This means a conditional 25% authored chance, then relative choice among those candidates—not 75% of all worlds for the first room. Both supplied rooms are valid candidates.
