# G7 evidence index

This directory retains G7 opening evidence and source-bound development/release
results. The complete outcome and acceptance matrix are in
[WORLDGEN_G7.md](../../docs/owner/WORLDGEN_G7.md).

- [Start and checkpoint](before/start.json): actual clean main and supplied ZIP hash.
- [Untouched brief](before/CODEX_G7_MULTI_BUILDING_COMPOUNDS.md) and
  [G6 review](before/G6_REVIEW.md): requested scope and prior findings.
- [Original review goal observations](before/optional_site_goals.json),
  [actual before probe](before/goal-result.json), and
  [after admission correction](admission/goal-result.json).
- [Capture record](before/capture/capture.json) and
  [original receipt](before/capture/receipt.json): genuine pre-edit G6 witness.
  The executable fixture is
  [authentic-g6-checkpoint.zip](../../tools/critical_fix_regressions/fixtures/g7/authentic-g6-checkpoint.zip)
  with its [binding](../../tools/critical_fix_regressions/fixtures/g7/g6-witness.json).
- [Opening allowed worker result](before/root-positive.json) and
  [synthetic rejection](before/root-negative.json). These were run while only the
  prior G6/baseline roots were allowed. The G7 guard separately certifies the newly
  permitted G7 root and rejects an OS-temporary synthetic root.
- [Admission focused receipt](admission/focused/receipt.json): 16 tests passed on
  the narrow correction before compound implementation.

The final input revision is `31afa301418d075d7a79252c19d04dfb13c4a174`.
Every final command records immutable input SHA, complete raw input
hashes, canonical-LF text hashes, args/cwd/environment, versions, exit/timeout and
output inventory. Binary files compare exactly. Uniform line-ending transformations
are reconstructable from Git; otherwise raw tested text is preserved. G6's missing
historical Markdown representation is not claimed to have been recovered.

Controlled recipe/ownership fixtures are distinct from the ordinary three seeds.
SVGs and their rasterizations are diagnostic diagrams. Files named `production.png`
use the actual app-local gameplay renderer with disclosed full-scene visibility.
Fixture positioning is disclosed separately from the real country-road journey.
Disposable save payload omissions, if any, are explicitly inventoried. Personal
campaigns, dependencies, browser profiles and whole production source ZIPs are not
included. Earlier evidence archives are preserved.

Expanded command directories move into the ignored review-only
`.baseline/g7-expanded-final-b/` after verification; the first freeze and development
directories remain under `.baseline/g7-expanded-final-a/`. Receipt paths describe the
actual command-time locations; ZIP paths and inventories map their retained bytes.
Ordinary disposable worker/capture runtime saves are omitted; the deliberately
retained authentic compatibility checkpoint remains a source fixture. Omitted
payload bytes cannot be reconstructed from their metadata alone.

[`checkpoint/worldgen-g7-verified-20261024-a`](https://github.com/dgobi/ResonanceRoguelike/tree/checkpoint/worldgen-g7-verified-20261024-a).
